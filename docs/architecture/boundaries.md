# Boundaries

Verified on **2026-09-07**. These are the ownership rules to preserve; known implementation deviations are called out here or in the [backlog](../plans/backlog.md). Trace executable code when an old comment disagrees.

## Backend call direction

```text
api/v1/ ──▶ services/ ──▶ models/ + core/database.py
   │           ├──▶ llms/ (text/image adapters)
   │           ├──▶ video_service / qwen_voice_service / tts_service
   │           └──▶ graph/graphs/context_graph.py (chat context)
   └──▶ schemas/ (typed requests and domain serializers)
```

1. **Endpoints orchestrate; services decide.** Reusable business rules belong in services. Some older endpoints still validate dict bodies and perform inline work; do not infer a universal typed API from `requests.py`.
2. **Keep provider details at the adapter boundary.** `llms/router.py` handles text/image routing and parsing; `video_service.py`, `qwen_voice_service.py`, and `tts_service.py` handle their media providers. Services own project workflows and billing; a provider adapter must not own episode state.
3. **SQLModel defines schema; Alembic versions it.** Change the model first, review an autogenerated revision, then check a temporary database. Historical backfills belong in migrations, never runtime `ALTER TABLE` or `create_all()` compatibility code.
4. **Close database sessions before awaiting a provider.** Use a short session to authorize/load configuration, await the provider, then a new short session to persist results and usage. SQLite has one writer; carrying a transaction through a long network call blocks unrelated work.
5. **Serialize explicitly.** Domain responses use `schemas/serializers.py`; job/export/usage/error services have their own wire serializers. These mint signed URLs and rename fields. Do not return ORM entities or decrypted configs directly.

## Frontend boundaries

```text
page / _components ──▶ actions/ ──▶ /api/bff/* ──▶ backend /api/*
         │                              ▲
         └──▶ local drafts / stores     └── next.config.ts fallback rewrite

chat controller ── AI SDK transport ──▶ real chat BFF stream route
```

- Ordinary API requests use actions and the shared axios client for JWT injection and 401 logout. Chat's transport is a separate, deliberate owner; see [chat design](../design/feature-chat.md). Signed media and legacy WebSocket traffic are direct-backend exceptions.
- A file under `src/app/api/bff/**` overrides the fallback for that path. Add one only when transformation is needed, and preserve authorization forwarding and the error contract.
- React Query owns fetched data; keys live in `actions/query-keys.ts`. The episode editor reads and polls the **same** project key. A separate poll key will leave its busy flag stale.
- Local state owns unsaved form/shot edits. The legacy workbench's `project-store` is an intentional in-memory working copy. The active unsaved-settings store records model-panel dirty flags only; it is neither draft persistence nor a backend configuration source.
- All new visible strings use both dictionaries in `lib/i18n.ts` through `useI18n()`. Route-local components go in `_components/`; reusable domain controls in `components/`; shared primitives in `components/ui/`.
- Fetch on the surface that needs the data. The project layout fetches the project list for its title/status; do not hoist unrelated config/history/media queries into the global workspace layout.

### Layout and chat composition

`(workspace)` and `(workbench)` are route groups, not URL segments. The project group supplies six sections; the episode and legacy editors are outside it. Active navigation comes from `usePathname()`. `/` redirects to `/chat`, `/admin` to `/admin/models`, and `/projects/:id` to `/projects/:id/info`.

AI SDK owns chat messages/stream state. assistant-ui's `useExternalStoreRuntime` supplies composer/attachment behavior and is scoped to the composer, while messages use a custom list. Do not introduce a second owner with `useChatRuntime`, a global assistant runtime, or a replacement `<Thread>` without revisiting [the design](../design/feature-chat.md).

## Wire contract and PATCH

**Both requests and responses use camelCase; Python attributes and storage use snake_case.** `CamelModel` accepts aliases (and Python field names via `populate_by_name`) and rejects extra fields. It does not rename keys in arbitrary response dictionaries. Legacy `dict[str, Any]` endpoints do not get its validation; inspect their code and generated schema.

For typed workbench PATCHes, use `model_dump(exclude_unset=True)`, then drop `None` where that field defines it as leave-alone. Never filter on truthiness: `false`, `0`, `""`, and `[]` can be intentional writes. **`is not None` does retain `false`.**

| Intent | Wire value | Stored / resulting behavior |
|---|---|---|
| Leave a typed optional field unchanged | absent or `null` | No update |
| Unbind a speaker/voice/owner | `""` | Service writes SQL NULL |
| Unlock a shot | `isLocked: false` | Persists false |
| Clear a model pick | config ID `0` | Falls back to account resolution |
| Clear prompt references or prefixes | `[]` | Persists an empty list; references become explicit |
| Turn a video frame slot off | `videoFirstFrame: ""` or `videoLastFrame: ""` | Stores JSON text `null`; `…Explicit` is true |

An untouched frame column contains an empty string; its response is also `null` but `…Explicit` is false. That distinction stops the editor from re-suggesting a frame the user deliberately removed. Error envelopes are `{"error": "..."}`; streaming and background failures have separate channels. Money crosses as strings, timestamps as ISO-8601 strings.

## Media and prompt boundary

Generated artifacts store paths relative to `SCENEFLOW_PRIVATE_GENERATED_DIR`. Signed URLs expire after 30 days and are minted per response with a stable UTC-day issue time. `Asset.path` may hold an explicitly imported external HTTP(S) URL; this exception must not spread to generated output columns.

References cross the API as `{kind, id}`, resolve with project ownership, and share a model-specific budget. Prefix references are deduplicated before a shot's own references, in the same order their text is concatenated. `prompt_compiler` owns provider positional labels. First/last frame payloads are distinct from additional reference media. The current storyboard loop uses saved per-shot references and does not silently append tone/predecessor images; legacy video/default and preview paths still have compatibility gaps described in the [data flow](data-flow.md) and backlog.

## Execution and concurrency

| Work | Current executor | State / stop mechanism |
|---|---|---|
| Character-state/prop image and prompt draft; project voice design/audition | In-process `job_worker.py` → `job_handlers.py` | `generation_jobs`, lease, heartbeat, DB cancel, explicit retry |
| Tone sheet, storyboard, legacy images, shot videos | API-created asyncio task | Project status claim, `runs.py` flag + task cancellation |
| Export | API-created asyncio task | Separate `export_jobs` row; no generation-worker lease or project lock |
| Breakdown, prompt optimization, cover, standalone media | Request handler | A client abort alone does not guarantee server/provider cancellation |
| Chat decisions | LangChain `create_agent` | SQLite conversation history; no configured durable production checkpointer/HITL flow |

The queue worker has **three lanes**, a **60-second lease**, and a **20-second heartbeat**. Job handlers receive plain job dictionaries and resolve model configuration inside the handler. Never put decrypted provider keys in `input_json` or other user-listable durable state. Paid jobs use `max_attempts=1`; an exhausted expired lease becomes `WORKER_LOST`, not an automatic paid retry. Manual `/retry` enforces the same attempt cap; an exhausted paid job needs a fresh enqueue if the user chooses to run it again.

`claim_project_status` is a conditional UPDATE. One rendering run owns a **series**, even when it targets one episode. Default batches skip locked shots; explicitly selecting a locked shot is rejected. `pendingOnly` skips already-successful shots. Exports read completed artifacts and write their own row, so they do not acquire that lock.

`runs.cancel()` sets its event **and calls `task.cancel()`** for attached tasks. Cleanup belongs to the task as it unwinds, not the cancel endpoint. Startup's `release_orphaned_runs()` clears locks left by a dead process without resuming work. Realtime, cancel registries, and startup recovery assume one backend process; a shared broker plus coordinated ownership/recovery is needed before splitting workers or scaling out.
